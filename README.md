# APE 5 – Manejo de archivos en Java

Este repositorio contiene los tres ejercicios de manejo de archivos desarrollados en Java.

## Contenido

| Archivo | Descripción |
|---|---|
| `CrearArchivo.java` | Crea el archivo `curso.txt` y verifica si ya existe. |
| `EscribirArchivo.java` | Solicita un mensaje y lo agrega al final de `estudiantes.txt`. |
| `EliminarArchivo.java` | Intenta eliminar el archivo `estudiantes.txt`. |

## Cómo ejecutar

1. Abre el proyecto en tu editor de Java o una terminal.
2. Compila el archivo que deseas ejecutar:
   ```bash
   javac CrearArchivo.java
   ```
3. Ejecuta la clase:
   ```bash
   java CrearArchivo
   ```

Repite el proceso cambiando el nombre de la clase por `EscribirArchivo` o `EliminarArchivo`.

## Requisitos

- Java JDK instalado.
- Un editor de código o terminal.

## Nota

Los archivos de texto `curso.txt` y `estudiantes.txt` se crean o utilizan durante la ejecución, según el ejercicio.
